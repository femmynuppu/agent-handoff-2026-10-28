# Security and evidence boundaries

- Dedicated directory/profile is not an OS sandbox. Actual probes: unshare user/mount/network namespaces returned EPERM; docker info returned socket permission denied. Arbitrary agent tools remain prohibited. A tools-disabled label does not prove an inherited Hermes gateway lacks file/shell tools or hidden prompt injection paths.
- Same Unix uid can edit configuration, lesson files and ledgers. Hash chains detect accidental inconsistencies, not a malicious same-user operator. No claim of cryptographic trust for serialized provider receipts or imported tool receipts.
- A2A accepts literal loopback HTTP only; refuses DNS, foreign origin, URL credentials and redirects. Authorization is never forwarded to advertised foreign URLs. Whole-request timer shuts down the underlying retained socket, including slow body reads. Response/request sizes and retry count bounded. Only safe discovery/GetTask operations retry. Send/cancel never replay automatically, including ambiguous failures or invalid responses.
- Agent Card protocol/auth validation does not attest selected backend model, absence of tools, spend limits or upstream identity. Token caps are not encoded in the inspected Hermes A2A API; verified provider enforcement is required before live calls.
- Cost reservation is durable before I/O; unknown or ambiguous usage remains reserved and blocks subsequent calls until independent receipt review. Calls are never refunded merely because transport failed.
- Teacher lessons are current OMP operator-attested artifacts, not student self-teaching mislabeled as teacher. Private answers/checks stay out of student task exports. Repository-private is not filesystem isolation; never grant student unrestricted access to this repository.
- Imported outputs are unverified descriptive artifacts. They cannot authorize lesson persistence, mastery or a controlled holdout pass. Deterministic matching is narrower than factual authenticity/generalization.
- MemPalace writes target only NEW scoped entities in the project KG, with installed resolved path asserted before dispatch. Lesson files are exclusive-created, hash verified, and pointer hydration refuses paths outside the project lesson directory. Only KG add/query is used; no cloud inference/downloads/drawer embeddings. Returned memory text remains untrusted instructional material.
- Logs redact configured credentials and common token patterns; raw model results are retained in private run artifacts for reproducibility. Do not put unrelated secrets in model prompts. Only project artifacts should be shared, after review.
- Tests identify scripted fixtures explicitly and never represent their responses as Hermes/model competency.
